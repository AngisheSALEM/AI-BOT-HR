# 🤖 Bot Highrise Savant - Hébergement Replit

## 🚀 Démarrage en 3 Minutes

### 1. Créer un Repl
- Aller sur **https://replit.com**
- **Create Repl** → Python → `highrise-bot-savant`

### 2. Uploader les Fichiers
- Uploader tout le dossier `hr bot python`
- Vérifier que `main.py` existe

### 3. Configurer les Secrets
Copier depuis `SECRETS-REPLIT.txt`:
- `BOT_TOKEN`
- `ROOM_ID`
- `ADMIN_USERNAMES`
- `GEMINI_API_KEY`

### 4. Lancer
- Cliquer sur **[Run]**
- Attendre "Bot connecté!"

### 5. Garder Actif 24/7
- Activer **Always On** (gratuit 3 mois)
- OU configurer **UptimeRobot** (gratuit à vie)

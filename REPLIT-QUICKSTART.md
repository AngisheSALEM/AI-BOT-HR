# 🚀 Démarrage Rapide Replit (5 Minutes)

## Étape 1: Créer un Repl
1. Aller sur **https://replit.com**
2. Se connecter / Créer un compte
3. Cliquer **"+ Create Repl"**
4. Choisir **Python** → Nommer: `highrise-bot-savant`

## Étape 2: Uploader les Fichiers
1. Cliquer sur les **3 points** à côté de "Files"
2. **"Upload folder"** → Sélectionner le dossier `hr bot python`
3. Attendre que tous les fichiers soient uploadés

## Étape 3: Configurer les Secrets
1. Cliquer sur l'icône **🔒 "Secrets"** (barre latérale)
2. Ajouter ces 4 secrets:

```
Key: BOT_TOKEN
Value: 057565bd7bda6ac37029f5817ea7c2f6d447179cdfa65771e41284ed5f5d6090

Key: ROOM_ID
Value: 680ab18546b31625a94de2e6

Key: ADMIN_USERNAMES
Value: sylver_ralx_lm

Key: GEMINI_API_KEY
Value: [votre clé Gemini]
```

## Étape 4: Lancer le Bot
1. Cliquer sur le gros bouton vert **"Run"**
2. Attendre l'installation des dépendances
3. Vérifier les logs: `[INFO] Bot connecté!`

## Étape 5: Garder Actif 24/7
1. Chercher **"Always On"** dans les paramètres
2. Activer (gratuit 3 mois)
3. OU utiliser **UptimeRobot** (gratuit à vie):
   - https://uptimerobot.com
   - Ajouter l'URL de votre Repl
   - Intervalle: 5 minutes

## ✅ C'est Tout!

Votre bot est maintenant en ligne 24/7!

Testez dans Highrise:
- `!help` → Liste des commandes
- `@savant bonjour` → Parler avec l'IA
